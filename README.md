# Vending machine — QA technical exercise

This repository is the **candidate-facing** copy of the vending machine exercise. It contains
`SPEC.md` and the JavaScript project under `javascript/`.

## Setup

Requires **Node.js 22** or newer.

```bash
cd javascript
npm install
npm test
npm start
```

Read [`SPEC.md`](SPEC.md) first, then [`javascript/README.md`](javascript/README.md) for how the
code and tests are organised.

Open this repository root in Cursor or VS Code to use the Mocha debug launch configurations in
`.vscode/launch.json`.
